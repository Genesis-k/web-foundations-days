About Quicknotes

Quicknotes is a simple web application that allows users to quickly capture and save their ideas before they disappear. It is designed to be user-friendly and accessible on various devices.

How to use Quicknotes

  1. Click the "New Note" button to create a new note.
  2. Enter your idea in the text area.
  3. Click "Save" to store your note.

Features

  • Quick and easy note creation
  • Responsive design for all devices
  • Simple and intuitive user interface

Keyboard Shortcuts

Shortcut Action
Ctrl + S Save current note
Ctrl + N Create new note
Ctrl + D Delete current note
